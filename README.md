## 🖥️ Run Locally

This is a static portfolio website, so you don't need a backend or database to run it.

### 1. Clone the repository

```bash
git clone https://github.com/ManjunathGlO/YOUR-REPOSITORY-NAME.git
```

### 2. Open the project

```bash
cd YOUR-REPOSITORY-NAME
```

### 3. Run the website

You can open `index.html` directly in your browser.

Or use **VS Code Live Server** for a better development experience.

## 🚀 Deployment

This portfolio is deployed using **GitHub Pages**.

### GitHub Pages Deployment

1. Push the project to GitHub
2. Open the repository
3. Go to **Settings**
4. Select **Pages**
5. Select the `main` branch
6. Select `/root`
7. Save the configuration
8. GitHub will generate the live website URL
